W

Native Windows interface

A .NET 10 WPF desktop app with dedicated navigation, status areas, and an in-app Activity log. The Python publishing worker runs separately in the background.

Q

Responsive large queue

A virtualized clip table updates changed rows instead of clearing and rebuilding the whole list during refreshes.

S

Flexible schedule controls

Choose the first post date, hour, minute, and AM/PM. The first post must be at least 15 minutes in the future. Set a posting interval from 5 minutes to 24 hours. Past start times are rejected, and no automatic next-slot shortcut is provided.

Y

YouTube Shorts + Facebook Reels

Choose YouTube, selected Facebook Pages, or both. Each destination's upload and scheduled status is tracked in the queue.

A

Account controls

See whether each platform is connected. Reconnect starts authorization again; Disconnect removes local tokens without cancelling accepted platform schedules.

M

Per-video metadata

Match MP4 clips with same-basename TXT files, preview titles and descriptions, edit metadata, and save changes for each clip.

H

Partial-upload protection

A clip stays in Detected with its local MP4/TXT files while any originally selected destination is pending, failed, or uncertain. It moves out only after every destination accepts the complete upload and returns an external video/Reel ID.

S

Dedicated Scheduled screen

See clips accepted by every selected destination, with the accepted publish time for each YouTube channel and Facebook Page. Scheduled means the platform accepted the upload and publish request; it does not mean the post is already public.

F

Safe to delete folder

After all selected destinations accept a clip, its MP4/TXT pair moves into the source folder’s You can delete this subfolder. The green SAFE TO DELETE button opens it in File Explorer. Local copies are never deleted automatically.

C

Clear Scheduled history

Clear visible Scheduled rows after the app creates and verifies a SQLite backup. This does not cancel platform posts, delete local files, or erase the permanent upload ledger and duplicate-prevention fingerprints.

V

Publication verification

Check whether scheduled uploads have become public and review failed or partial destinations from the Activity log.

Getting started

Set up once. Then manage your queue.

The application uses your own Google and Meta authorization, stored locally in your Windows user profile.

1. Install on Windows

Download and run ScarClipScheduler-Setup.exe. The visible PowerShell setup runs `python --version` from the current Windows PATH and validates 64-bit CPython 3.10 or newer. If no compatible command exists, it tries WinGet first; if WinGet is unavailable or fails, it downloads the latest stable 64-bit Python installer from python.org, verifies its digital signature, and installs it for the current Windows user. It then creates and checks the publishing-worker environment. A healthy existing environment is reused without reinstalling packages. This setup runs during installation only.

  • The WPF executable is self-contained for .NET 10.
  • 64-bit CPython 3.10 or newer is used by the publishing worker.
  • Internet is needed only for automatic Python setup (when required), first-time package installation, and platform API access.

2. Connect YouTube

Enable YouTube Data API v3 in Google Cloud, create an OAuth 2.0 Desktop application client, and choose the downloaded JSON file in Connections.

  • An API key alone is not enough for uploads.
  • Sign in to the Google account that owns the channel.
  • Reconnect starts a fresh Google authorization.

3. Connect Facebook

Create a Meta developer app, configure the required Page permissions and localhost redirect URI, then enter the Meta App ID, App Secret and Business Portfolio ID.

  • The connecting account needs access to the Pages.
  • Choose which connected Pages should receive Reels.
  • Reconnect starts the authorization flow again.

4. Review the schedule

Choose the first-post date, hour, minute, and AM/PM. The time must be at least 15 minutes ahead, and the interval can be 5 minutes to 24 hours. Scheduling uploads videos now and asks each selected platform to publish at its assigned time. The app records each platform’s accepted publish time.

  • A platform-accepted schedule is not yet a public post.
  • Use Check publication to verify later.
  • Removing a local row does not cancel platform-side posts.

Good to know

Frequently asked questions.

How do I uninstall ScarClipScheduler?

Use Start Menu → ScarClipScheduler → Uninstall ScarClipScheduler, or Windows Settings → Apps → Installed apps. Uninstalling removes the program files and shortcuts while keeping your local queue, settings and authorization data for a later reinstall.

Where can I find an installer error?

If a prerequisite check fails, the setup window remains open until you press Enter. The full PowerShell transcript is saved to %LOCALAPPDATA%\ScarClipScheduler\installer-setup.log. The installer does not report success when prerequisite setup fails.

Does the app need a support terminal?

No. The WPF interface starts the local Python publishing worker in the background. Scan, upload, schedule, verification and error messages appear in the in-app Activity log. A separate PowerShell window is shown during installation only, when prerequisites are checked or installed.

Does deleting a clip from the queue delete its MP4?

No. Delete from list removes local queue records and Page-job tracking. It does not delete source MP4/TXT files or cancel schedules already accepted by YouTube or Meta.

Can I schedule just one video?

Yes. Select one row for one video, or use Ctrl/Shift to select multiple clips. With no rows selected, scheduling applies to the full queue.

Does Scheduled mean the post is already public?

No. Scheduled means every selected destination accepted the complete upload and returned its video/Reel ID. The platform may still be waiting for the assigned publish time. ScarClipScheduler verifies publication separately after the scheduled time.

What does the SAFE TO DELETE button do?

It opens the You can delete this subfolder inside your selected source folder. ScarClipScheduler moves an MP4 and matching TXT there only after every originally selected destination accepts the complete upload. You may manually delete those local copies when you no longer need them; the app does not delete them automatically.

What does Clear history remove?

It removes the visible Scheduled rows from this app after creating and verifying a SQLite backup. It does not cancel YouTube or Meta posts, delete MP4/TXT files, or erase the permanent upload ledger and duplicate-prevention fingerprints. Cleared rows cannot be restored from the app.

Why is a clip still in Detected?

At least one destination from that clip’s original publishing plan has not yet accepted the complete upload. Pending, failed, partial, and uncertain destinations keep the clip and its local files in Detected so you can retry or verify them.

Does the app provide Google or Meta credentials?

No. You create and authorize your own developer credentials. The app stores its tokens locally and never packages them in the public release.
