Getting started

Set up once. Then manage your queue.

The app uses official platform authentication flows. You need your own developer credentials before publishing.

1. Install on Windows

Download the EXE from Releases and open it. On first launch, the bootstrapper checks for Python 3.11+, attempts a per-user Python 3.12 install through Windows Package Manager if needed, creates an app virtual environment, and installs required packages from the internet.

  • Internet access is required for initial setup.
  • Python may need to be installed manually if winget is unavailable.
  • The EXE is unsigned, so SmartScreen may display a warning.

2. Connect YouTube

Create a Google Cloud project, enable YouTube Data API v3, configure OAuth consent, and create an OAuth Client ID for a Desktop app. Add the downloaded client JSON in the scheduler.

  • An API key alone is not enough for uploads.
  • Use OAuth 2.0 Desktop App credentials.
  • See the README for the detailed setup walkthrough.

3. Connect Facebook

Create a Meta developer app and configure the required Page publishing permissions. Enter your own App ID and App Secret in the scheduler.

  • Access to a Facebook Page with the required role is needed.
  • Meta review or business verification may apply to some permissions.
  • See the README for permission and redirect details.

4. Keep credentials private

Use your own platform accounts and developer credentials. Do not upload OAuth files, tokens, app secrets, or local database files to GitHub or share them publicly.

  • Review privacy and security guidance in the README.
  • Keep a backup of local queue data.
  • Removing a queue entry does not cancel an already-accepted platform schedule.
The release EXE is a small Windows bootstrapper, not a self-contained Python runtime. It locates or installs Python and downloads app dependencies during first-time setup.

Good to know

Frequently asked questions.

Is the EXE a fully portable app?

No. It is a bootstrapper that locates or installs Python and installs app dependencies the first time it runs. Internet access is required during setup.

Does deleting a clip from the queue delete its MP4?

No. Delete from list removes local queue records and related local job tracking. It does not delete source MP4/TXT files or cancel schedules already accepted by YouTube or Meta.

Can I schedule just one video?

Yes. Select one video to schedule only that video, or use Ctrl/Shift to select multiple. With no selection, scheduling applies to the full queue.

Does the app provide API credentials?

No. You must create and supply your own Google Cloud OAuth credentials and Meta developer app credentials. Detailed instructions are in the README.
