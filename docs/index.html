Getting started

Set up once. Then manage your queue.

The application uses your own Google and Meta authorization, stored locally in your Windows user profile.

1. Install on Windows

Download the Windows x64 ZIP, extract it, and run Install-ScarClipScheduler.ps1. Setup installs the native app, prepares the isolated Python worker environment, and creates a Start Menu shortcut.

  • The WPF executable is self-contained for .NET 10.
  • Python 3.11 or newer is used by the publishing worker.
  • Internet is needed for first-time dependencies and platform API access.

2. Connect YouTube

Enable YouTube Data API v3 in Google Cloud, create an OAuth 2.0 Desktop application client, and choose the downloaded JSON file in Connections.

  • An API key alone is not enough for uploads.
  • Sign in to the Google account that owns the channel.
  • Reconnect starts a fresh Google authorization.

3. Connect Facebook

Create a Meta developer app, configure the required Page permissions and localhost redirect URI, then enter the Meta App ID, App Secret and Business Portfolio ID.

  • The connecting account needs access to the Pages.
  • Choose which connected Pages should receive Reels.
  • Reconnect starts the authorization flow again.

4. Review the schedule

Choose the local first-post time and posting interval. Scheduling submits videos now and records the time accepted by each platform.

  • A platform-accepted schedule is not yet a public post.
  • Use Check publication to verify later.
  • Removing a local row does not cancel platform-side posts.

Good to know

Frequently asked questions.

Does the app need a support terminal?

No. The WPF interface starts the local Python publishing worker in the background. Scan, upload, schedule, verification and error messages appear in the in-app Activity log.

Does deleting a clip from the queue delete its MP4?

No. Delete from list removes local queue records and Page-job tracking. It does not delete source MP4/TXT files or cancel schedules already accepted by YouTube or Meta.

Can I schedule just one video?

Yes. Select one row for one video, or use Ctrl/Shift to select multiple clips. With no rows selected, scheduling applies to the full queue.

Does the app provide Google or Meta credentials?

No. You create and authorize your own developer credentials. The app stores its tokens locally and never packages them in the public release.
